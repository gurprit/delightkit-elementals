# DelightKit Elementals Lab 🔥❄️🌸🫧✨

A live browser playground for tuning tactile particle microinteractions.

## Open it live

- StackBlitz: https://stackblitz.com/github/gurprit/delightkit-elementals?startScript=dev
- Codeflow / PR editing: https://pr.new/github.com/gurprit/delightkit-elementals

GitHub is the source of truth. The lab deliberately uses plain JavaScript + CSS + Vite so visual experiments stay fast. Finished effects can later be packaged as React, Shopify or vanilla components.

## Current Elementals

Embers, Frost, Petals, Bubbles and Stardust.

## Local

```bash
npm install
npm run dev
```
